I'm a backend-focused software developer with a strong interest in clean, maintainable architecture and scalable systems. Over the past several years I've worked across .NET, ASP.NET Core, and modern cloud-native patterns, building products that need to hold up under real production load rather than just look good in a demo. I care as much about the shape of the code — how easy it is for the next developer to reason about — as I do about the feature actually working. Alongside client and product work, I teach programming courses and write technical articles, because explaining a concept clearly is usually the fastest way to find out whether I actually understand it. I enjoy pairing pragmatic, well-tested code with architecture patterns like Clean Architecture and CQRS when the complexity of a project genuinely calls for them — and staying away from them when it doesn't. Outside of core development, I spend time exploring event-driven systems, mentoring newer developers, and contributing small tools and samples back to the community on GitHub. I'm always happy to talk through an interesting technical problem, a course idea, or a potential collaboration.
