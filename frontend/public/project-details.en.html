OcanelShop — Large E-Commerce Store

A large online store built as two parallel versions to showcase two different architectural approaches in .NET: one built on Minimal API and Clean Architecture, the other a full-stack approach with MVC and Razor Pages.

C# / ASP.NET Core Clean Architecture In active development

I designed OcanelShop from scratch to be both a real, complete online store and a place to demonstrate two different architectural approaches for .NET projects. That's why the project is developed as two parallel versions, each following a different architectural path.

Two versions, two architectural approaches

The first version is built on Minimal API and Clean Architecture, following a full separation of layers (Domain, Application, Infrastructure, and Presentation). The second version takes a full-stack approach with MVC and Razor Pages, using a Razor Class Library to manage the UI in a modular way.

Key features

  • CQRS + MediatR: Separates read and write paths for better scalability.
  • Authentication: User and access management with JWT and ASP.NET Identity.
  • Two-tier caching: Uses Redis to reduce database load in high-traffic scenarios.
  • Deployment: Fully containerized with Docker for consistent behavior across environments.

What's next for the project

The project is currently a modular monolith, and the next step is a gradual migration to microservices — starting with strengthening the messaging layer (RabbitMQ) and gRPC, followed by patterns like Saga for managing distributed transactions.
