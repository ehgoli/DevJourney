OcanelShop — فروشگاه اینترنتی بزرگ

یک فروشگاه اینترنتی بزرگ که در قالب دو نسخه موازی ساخته شده تا دو رویکرد معماری متفاوت در دات‌نت را نشان دهد؛ یکی بر پایه Minimal API و Clean Architecture، و دیگری با رویکرد فول‌استک MVC و Razor Pages.

C# / ASP.NET Core Clean Architecture در حال توسعه

OcanelShop را از صفر طراحی کردم تا هم یک فروشگاه اینترنتی واقعی و کامل باشد، و هم محلی برای نشان‌دادن دو رویکرد متفاوت در معماری پروژه‌های دات‌نتی. به همین دلیل پروژه در قالب دو نسخه موازی توسعه داده شده که هرکدام مسیر معماری متفاوتی را دنبال می‌کنند.

دو نسخه، دو رویکرد معماری

نسخه اول بر پایه Minimal API و Clean Architecture ساخته شده و جداسازی کامل لایه‌ها (Domain، Application، Infrastructure و Presentation) را دنبال می‌کند. نسخه دوم با رویکرد فول‌استک شامل MVC و Razor Pages پیاده‌سازی شده و از Razor Class Library برای مدیریت ماژولار رابط کاربری استفاده می‌کند.

ویژگی‌های کلیدی

  • CQRS + MediatR: جداسازی مسیرهای خواندن و نوشتن داده برای مقیاس‌پذیری بهتر.
  • احراز هویت: مدیریت کاربران و دسترسی‌ها با JWT و ASP.NET Identity.
  • کش دو سطحی: استفاده از Redis برای کاهش فشار روی دیتابیس در سناریوهای پرترافیک.
  • استقرار: کانتینری‌سازی کامل پروژه با Docker برای اجرای یکسان در محیط‌های مختلف.

مسیر بعدی پروژه

پروژه در حال حاضر به یک مونولیت ماژولار تبدیل شده و قدم بعدی، مهاجرت تدریجی به میکروسرویس‌هاست؛ با شروع از تقویت مهارت‌های مرتبط با پیام‌رسان‌ها (RabbitMQ) و gRPC، و سپس پیاده‌سازی الگوهایی مانند Saga برای مدیریت تراکنش‌های توزیع‌شده.
